# Research — Wave 4 (Timer authority, focus queue, tracked time + Profile)

## Scope
Timer remains SERVER AUTHORITATIVE: `projectElapsedSeconds(startedAt, nowMs)` recomputed every second from canonical `activeSession.startedAt`, fallback `elapsedLabel` when parse fails. 1s projection must be isolated to `TimerClock` only — no full-screen, queue, or nav rerender. Focus queue limited to 12 open tasks (`status !== done` sliced), `selectedTaskId` single pick then `Start timer`; stop via `activeSession.sessionId`. Summary four metrics: `trackedTodayLabel`, `sessionsTodayCount`, `longestSessionLabel`, `trackedTotalLabel`. States: loading skeletons, offline full retry, stale banner, retry, pull refresh. Profile is NOT a primary tab (avatar → `/(app)/profile` stack, hidden compat keeps deep link). Identity: initials from `email.substring(0,2)`, email, auth pills, workspace pills, sign out (`Constants.expoConfig.version`), compact sign-out layout. No decorative background loop, no tick >1s, no client-accumulated elapsed. References evaluated as patterns only; no code copied.

### Mobbin — Focus Timer & Live Clock Isolation (Toggl Track, Forest, Sunsama Focus, Structured Timer, Linear Time Tracking)

| Field | Detail |

| SOURCE | Mobbin — production timer/focus screens (Toggl Track running timer: large `HH:MM:SS` mono 48–56/700–900 centered + `Running • Task title` + `Started at h:mm AM/PM` + Stop danger pill; Forest focus timer: ring + centered clock 52/900 tracking -1 capped 1.6 + started meta; Sunsama focus queue: pick-one-of-12 cards then large Start; Structured/Todoist timer: offline banner `cloud-offline` + Retry ghost) — queried “timer focus queue”, “tracked time”, “pomodoro clock”, “today time” |
| PATTERN | Active session is a centered Card: top row `10 dot successMid + Running` 12/800 uppercase, title 17/700 two-line centered, clock 52/900 -1 monospaced-ish 00:00 / 1:00:00 switching at 3600, `maxFontSizeMultiplier 1.6`, `accessibilityLabel Elapsed {label}`, startedAt `Started at h:mm` 12 muted centered; bottom `Stop timer` danger pill full width 54h with stop icon 22. Idle state is picker Card: header `Pick a task to time` 16/800, 12 rows `Pressable` 44 min (border 1 + radius md, selected `surfaceMuted + accentMid` border + checkmark-circle accent 20), row title 14/600 + meta `Project · status` 12 subtle, trailing check only when selected, bottom `Start timer` primary 52h play 20 disabled until selection. Summary is second Card: header `timer-outline 18 accent + Tracked time` 16/800, stats row 3× flex1 centered — `22/900 value + 11/700 label uppercase` for Today/Sessions/Longest, footer `All time · {label}` 12 muted centered. Clock ticks 1s via isolated interval; queue/summary/header never rerender on tick (verified by separate component). |
| WHY IT HELPS | Large centered clock matches Toggl/Forest reading at arm’s length; Running dot + taskTitle grounds session (user forgets which task is timing after switch). Capping font scale prevents HH:MM:SS wrapping to two lines on Dynamic Type XL. Isolated tick avoids FlatList/ScrollView churn: on the 50-row task picker, a full-screen setState every second would thrash `ScrollView` layout and invalidate `HeaderActions` avatar press. Server authority (`startedAt` ISO → `projectElapsedSeconds`) guarantees clock reconciles after background/killed app: local accumulation would drift when JS throttled in background. 12-row cap keeps picker scannable without virtualization while matching `MAX_PICKER_TASKS`. Summary 3+1 layout (3 centered stats + footer all-time) avoids metric overload; Today/Sessions/Longest cover day focus, All Time covers history. |
| WHAT WE ADOPT | `features/timer/components/TimerClock.tsx` owns `nowMs` + `setInterval 1000` + immediate `setTimeout 0`, recomputes `projectElapsedSeconds(startedAt, nowMs)` every render, fallback to `activeSession.elapsedLabel` when `null`, renders `Text maxFontSizeMultiplier 1.6 style clock 52/900 -1`. Parent `timer.tsx` holds NO `nowMs`; interval lives only in `TimerClock`. `FocusQueue.tsx` Card variant with `EmptyState icon list-outline` when 0, else title + map 12 `Pressable taskRow` 44 min with `accentMid` selected + `Button Start timer primary 52h play` disabled `!selectedTaskId \|\| isStarting`. `TrackedTimeSummary.tsx` Card with `statsRow flex row gap sm` each `statBlock flex1 align center`. No `Animated.loop` or background blur decoration. |
| WHAT WE REJECT | Accumulating `seconds++` local counter (drifts, violates server authority); ticking parent `TimerScreen` with `nowMs` state (rerenders queue/summary/nav every second, breaks spec); increasing to 100ms or `requestAnimationFrame` for smoothness (battery, violates 1s cap); decorative pulsing ring or blurred gradient behind clock (distracts, perf, “No background decorative loop” spec); virtualized `FlatList` for 12 rows (overkill vs mapped `Pressable`s, adds windowing complexity); showing estimate or focusRank inside queue row (project status already, keep row minimal 2-line); inline `ActivityIndicator` spinner overlay hiding queue during tick (hidden). |

## Cross-reference Decisions (Wave 4)

- **Server authority & isolation:** `TimerClock` owns `nowMs` + `setInterval 1000` + immediate `setTimeout 0`, recomputes `projectElapsedSeconds(startedAt, nowMs)` every render, falls back to `elapsedLabel` when `null`. No other component holds `nowMs`. Parent `TimerScreen` never rerenders on tick → FocusQueue, TrackedTimeSummary, ScreenHeader, BottomNavigation stable. Verification via React DevTools profiler: Clock updates per second, siblings 0.
- **Tick constraints:** Interval 1000ms only, no `requestAnimationFrame`, no accumulation, no background loop. `formatElapsedClock` pure, no side effects. `CLOCK_MAX_FONT_SCALE 1.6` preserved.
- **FocusQueue ownership:** `candidateTasks` = `tasksQuery.data.tasks.filter(status!==done).slice(0,12)` via `useMemo` stable; `MAX_PICKER_TASKS 12` preserved. Selection is local `selectedTaskId` state, disabled start when `!selectedTaskId` or `activeSession` present. Mutually exclusive with active Card (queue hidden when running).
- **Summary metrics:** `TrackedTimeSummary` consumes `TimerSessionSummary` directly (`trackedTodayLabel`, `sessionsTodayCount`, `longestSessionLabel ?? "—"`, `trackedTotalLabel`). No client recompute of labels. Footer `All time · {label}` matches prior `workspace.summary` display.
- **Offline/loading states:** `isPending && !workspace` → 2× `SkeletonCard`; `isError && !workspace` → offline Card + Retry `Button secondary` invoking `workspaceQuery.refetch()`; `showStaleBanner = isError && !isFetching` → `FeedbackBanner neutral` with `cloud-offline`. `RefreshControl refreshing={isRefetching}` keeps stale content. `tasksQuery.isFetching && !data` → `ActivityIndicator accent`.
- **Virtualization & clearance:** `ScrollView` (not FlatList — queue is 12 rows max + 2 cards) with `contentContainerStyle gap md paddingBottom floatingTabClearance 160 paddingHorizontal lg 20 paddingTop sm + showsVerticalScrollIndicator false`. No `ScrollView+map` beyond 12, no `FlatList` needed. Retains parity with prior padding.
- **Design primitives:** `AppScreen padded false`, `ScreenHeader eyebrow Focus title Timer description … + HeaderActions rightSlot`, `Card`, `Button primary/danger secondary`, `FeedbackBanner`, `SkeletonCard`, `EmptyState`. No `MobileScreen/GlassCard/GlassButton/GlassPill`. `BottomNavigation` unchanged, hidden routes stay `href:null`.
- **Profile routing:** Canonical `app/(app)/profile.tsx` via `Stack.Screen name=profile headerShown true title Profile`. Compat `app/(app)/(tabs)/profile.tsx` stays `href:null` but renders `Redirect` to canonical; hidden from tab bar. Avatar in `HeaderActions` (all tabs + search) pushes to `/(app)/profile` — already verified. Compact sign-out: Card row with helper + `Button danger sm`, not full-width. Pills are neutral semantic Views, not invented Chip status. Version from `Constants.expoConfig.version ?? 1.0.0`.
- **Validation:** `git diff --name-only dca2dce…HEAD` + `ls-files --others` both `apps/mobile/**` only via `awk '!/^apps\\/mobile\\//'`. `npx tsc --noEmit` exit 0. `npm run test` (apps/mobile) + `npm run mobile:test` same. `git diff --check` clean. Mobile-only diff verified per wave. `HeaderActions` profile navigation manual tap check.
