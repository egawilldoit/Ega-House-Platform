# Research — Wave 5 (Welcome + Login dark auth + Search immediacy)

## Scope
Welcome/Login remain DARK AUTH identity (`authBackground #0d1117`, `authSurface #161c28`, `authCircleBlue/Purple`, `accent #2563eb`) — do NOT force primary white `AppScreen` onto auth. Headline must be clear (`Your execution\ncommand center` preserved) + short supporting copy (`Tasks, focus sessions, and daily momentum — all in one place.`) + single CTA `Get started → /login`, no heavy startup animation (spec forbids pulsing ring, looping blur, or Lottie hero). Login preserves `isValidEmail /^[^\s@]+@[^\s@]+\.[^\s@]+$/` + password ≥6 + `clearError` + `signIn(email.trim(), password)` → `router.replace("/(app)/(tabs)/today")` + back `router.replace("/(public)/welcome")` + `minHeight 20` error reserve (no layout shift) + loading `ActivityIndicator` + keyboard-safe without new deps. Search preserves debounce 250ms + limit 200 (`SEARCH_TASK_LIMIT`) + truncation warning (`Showing first X of Y tasks…`) + groups Tasks / Projects / Goals with navigation `/(app)/tasks/[id]`, `/(app)/projects/[slug]`, `/(app)/(tabs)/goals` (`Goal` detail also via `/(app)/goals/[id]` supported but current design routes to tab) + `searchWorkspace` pure client filter over cached `useTaskListQuery`/`useProjectListQuery`/`useGoalListQuery` (no per-keypress fetch, immediacy via debounce only). Search must feel immediate — cached query data reused, debounce timer only, no server round-trip per keypress. Visuals migrate `GlassInput/GlassCard/GlassPill/MobileScreen` → `SearchField/Card/FeedbackBanner/EmptyState` via `mobileTheme` tokens; auth keeps `auth*` palette separate. References evaluated as patterns only; no code copied.
