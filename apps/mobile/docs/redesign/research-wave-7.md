# Research — Wave 7 (Detail / Edit: Task · Project · Goal)

## Scope
Wave 7 migrates `apps/mobile/app/(app)/tasks/[id]`, `projects/[slug]`, `goals/[id]` from `MobileScreen`/`Glass*` to `AppScreen` + `Card` + `FormSection` + `FormField`/`Chip`/`SegmentedControl`/`SelectionRow`/`Button`/`FeedbackBanner`/`ProgressBar`/`Skeleton` + sticky save bar (`stickyActionClearance 120` outside `ScrollView`, inside `KeyboardAvoidingView`, floating 120) + `keyboardShouldPersistTaps handled`. Must preserve **every current capability verbatim** — not just happy-path fields but error strings, timezone logic, dirty detection, validation, reminder history, recurrence. No new endpoints, no API behavior change, no query-key drift. Feature screens move under `features/{tasks|projects|goals}/detail/`; routes become thin delegates. References evaluated as patterns only; no code copied. Stitch MCP prompts below describe refine targets (offline spec until green-run `refine_screen` export).

## Cross-reference Decisions (Wave 7)

- **Detail IA authority:** `features/tasks/detail/TaskDetailScreen.tsx` owns all query/mutation/draft/reminder state and compose **6 sections** as dumb children: `TaskIdentityCard` (`{task}`), `TaskStateSection` (`{draft,onChange:setDraft,…}`), `TaskScheduleSection` (`{draft,applyQuickDueDate,setDraft,isSubmitting}` with recurrence/timezone helper), `TaskReminderSection` (`{reminders,pending,completed,reminderDate,mode,visible,cancellingId,isSubmittingReminder,onOpenPicker,onChangeDate,onCreate,onCancel,reminderError/Success}`), `TaskDetailsSection` (`{draft,setDraft}` description/blockedReason with helper), `TaskSaveBar` sticky (`{dirty,isSaving,submitError,successMessage,onSave,onBack}`). Children receive props, never own queries or `useTaskByIdQuery` authority (single-owner rule). Formatters (`formatDueDate`, `formatTimestamp`, `formatReminderTimestamp`, `formatRecurrenceRule`, `formatReminderDraft`, `sortReminders`, `isoDateAtOffset`, `createEditableDraft`, `isDraftDirty`, `createDefaultReminderDate`) live in `detail/formatters.ts` or `features/tasks/form-utils.ts` sharing with create where possible; `validateEstimateMinutesInput` + `formatTaskToken` stay canonical. `FormSection` primitive authority unchanged (header icon 16 muted + Title 14/800 + description 12 muted + `Card surface #fff border #e4e7ec card 20 shadow card gap 8` + outer `marginTop md`). No per-section `SectionTitle` duplication.
